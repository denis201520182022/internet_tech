Название проекта: Проект "Путешествия по России"
Краткое описание: Адаптивная веб-страница о красивых местах в России. Проект демонстрирует навыки работы с Flexbox, Grid Layout и медиа-запросами.
Использованные технологии: HTML5, CSS3 (Flexbox, Grid Layout, Media Queries), БЭМ (Nested).
